# 墨控 InkControl 0.1.1-rc17

面向 **Hisense A5 Pro 经典版黑白屏**的候选预发布。本版本在 rc16 基础上集中调整界面与锁屏排版：首页把「已开启/总数」并进分类标题、状态概览压缩成一行、安装与诊断合并为「模块设置」标签；新增结果提示的显示时长控制；锁屏新增「编辑排版-横」与「编辑排版-横-逆」两套横版样式，并修复逆版样式不生效的问题。**62 个增强全部默认关闭**。

版本号由 0.1.0 升为 0.1.1：本版含界面与锁屏行为变化，按仓库规则必须新版本，不覆盖 rc16 的 Release。

## 界面与交互

- 首页标题右侧显示版本号，去掉「墨水屏增强 · 全部默认关闭」副标题；「已开启 / 待重启 / 异常」压缩为标题下方一行数字，待重启与异常为 0 时不再显示。
- 分类入口把统计并进标题行，形如「显示 | (5/10)已开启」，去掉单独一行统计文字，卡片随之变矮。
- 底部「安装」「诊断」合并为「模块设置」标签：入口页集中放置安装、诊断、实验室、名词解释与「中 / EN」语言切换，并注明英文翻译已停止维护。
- 模块设置新增「提示时长」：修改设置后的结果提示可选 5 秒 / 30 秒 / 60 秒 / 不显示，默认 30 秒后自动消失；失败提示不自动消失，仍需手动关闭；选「不显示」时提示条不再占用详细调整区的空间。该偏好在 App 内保存，不影响功能配置与后端校验。
- 分类顺序调整：锁屏与动画位置互换；自定义锁屏选项中的液态玻璃置底。

## 锁屏

- 新增「编辑排版-横」：720×360 横版构图整体旋转铺满竖屏面板，横转手机即可阅读；表头为大号英文日期与第 N 日、中文日期、衬线大字时间，右侧为倒数日框，右下为电池与通知，左下为中英格言。
- 新增「编辑排版-横-逆」：与横版同一构图整体旋转 180°，适合手机反向横转阅读。「上滑解锁」提示列已移到画布最左缘，箭头方向随样式翻转，竖屏面板上始终指向真实的上滑解锁方向。
- 修复「编辑排版-横-逆」选中保存后锁屏仍回退系统样式：原厂 `EinkKeyguardController` 只接受 0–9 的 `eink_keyguard_style`，写入 10 会被重置为 0；现改为把逻辑值 10 折算成物理样式 9（复用横版槽位），旋转 180° 由绘制层按逻辑值判定，配置与生效回执仍用逻辑值，状态可正常显示「已生效」。
- 自定义锁屏样式继续不叠加原厂底栏；像素主题保持纯白背景。

## 安装与验证范围

使用本 Release 的 APK；配套后端已内置，也提供同版本 ZIP。适配门槛：HLTE203T、API29、arm64、L1732.6.01.02 及准确原厂输入哈希。rc13 起的新签名不能覆盖旧签名 App；首次迁移先备份配置并卸载旧 App，再安装新版与匹配后端。

**App 与后端模块必须同版本一起安装**：只替换 APK 而保留旧后端模块，开机完整性校验会失败并写入 `skip_mount`，App 首页将提示「环境未就绪 / 安装未完成」。升级时先安装新 APK，再安装同一次构建产出的后端 ZIP，然后整机重启。

发布门槛：云端回归、原生/GPU 对照、App/Overlay 签名、包装校验、四组中英文界面检查。本版界面与锁屏排版已在本机 rc16 装机过程中逐项对照，rc17 的云端回归与完整实机验收仍待执行；自动刷新、真实 HWC 集成、面板、温区、功耗、长稳仍待独立验收。历史首 GPU 错误根因未确定；Google split 图标覆盖保持关闭。
