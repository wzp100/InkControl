# 墨控 InkControl 0.2.5-r23

面向 **Hisense A5 Pro 经典版**（`HLTE203T` / Android 10 / arm64）的候选版本，版本号 `0.2.5-r23`，versionCode 23。全部增强默认关闭；只有锁屏「设备状态」的四项显示开关与「截屏便签对齐尺寸」默认开启，翻页动画的风格／速度／分块是必选参数（无开关）。

## 本版内容

- **翻页动画**：由 **nuku 大佬**制作，经其同意整合进墨控。不再需要第二个 Magisk 模块或独立 App，前端在「锁屏主题」与「动画」之间新增大功能，九个配置项在一页内用下拉与开关设置（六种揭示风格、分块默认 12 块），目标阅读器由用户自己选应用、出厂不内置名单。
- **后端**：一个 `inkcontrol_backend` 内放三份 HWC，开机按 `pageanim.master` 选挂翻页动画库或墨控 GPU 库；常驻端与配置到 `settings.conf` 的翻译也收进同一模块，冲突名单补上旧独立模块。热改动画参数无需重启，换库必须完整重启。
- **界面**：带入 0.2.4-r21 的全局紧凑页、上下双线选中态与去数量口径；「显示信息修改」改成展开式多选；数值项支持自定义，周期性刷新默认 5 分钟；不再保留调试期的文案热更新通道。
- **面板**：动作表新增「翻页动画」（单击开关、长按进设置页）；「锁屏主题」单击改为直接进样式页。开关状态即时同步到 App 内开关；墨控被强制停止后由透明页兜底完成切换，不会误报「已打开／切换失败」。
- **其它**：横版锁屏长格言上移避免被裁；诊断页在作用域回执全空时直说「模块未注入」；体感、字体、备份等处的文案精简；`tools/` 收录锁屏截图与解锁工具（不含任何真实 PIN）；中文文档补齐 GPU 后端与翻页动画的互斥说明。

## 重要限制

- **翻页动画与 GPU 显示后端（`display.gpu`）目前不能同时启用**：两者替换同一份 `hwcomposer.ums512.so`，同时开启时翻页动画优先，墨控的分模式算法、迟滞、触摸加速、波形动画与「全刷扫过」全部停用。App 里 `display.gpu` 显示「已开启」只是配置，不代表库已挂载；来回切换必须**完整重启**。
- `pageanim.master` 是 REBOOT 项，只改配置不重启不会换库。第三方原生二进制与 HWC 派生库不在公开仓库，云端构建需另行准备输入。
- **未验收**：翻页动画的实际观感（需先在 App 里选阅读器）、与 GPU 后端来回切换多次后的稳定性、长时间功耗与温区。未列出的效果不做承诺。

## 验证范围

电脑端：`build.py` 全量 javac + v3 签名；`tools/test.py --fast` 全绿；`check_docs.py` / `check_repository.py` / `check_i18n.py` 通过。Python 侧仍有仓库既有的 12 项红（`test_gpu_diagnostics` / `test_backend`），与本版改动无关。

真机（`HLTE203T`，无线 adb）：本版用 `install -r` 同批安装 APK 与后端模块并完整重启，`dumpsys package` 显示 `0.2.5-r23` / `versionCode=23`，`sys.inkcontrol.ready=1`、模块目录无 `error`／`disable`，HWC 为翻页动画库、常驻端在跑；首页显示 `v0.2.5-r23`「就绪」，体感新文案、翻页动画页的四个下拉与总开关、墨控四按钮快捷面板均复核，原有配置保留。此前几轮的紧凑页、面板开关同步、强制停止兜底、横版锁屏抓图与自定义数值实测结论沿用。以上为单机单次实测，不等于面板观感、功耗、温区或长期稳定验收。
