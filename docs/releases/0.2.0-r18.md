# 墨控 InkControl 0.2.0-r18

面向 **Hisense A5 Pro 经典版黑白屏**的候选预发布。本版在 0.1.1-rc17 基础上整理功能结构与显示算法：锁屏通知合并为单一开关、体感去掉总开关并把遮挡延时并入「行为」、动画与全刷扫过保留总开关与实验标记口径调整；显示侧「改用原厂显示算法」改为完全旁路并修复波形动画能力下发，新增「每个模式单独选原厂算法」。**67 个增强全部默认关闭**。

版本号按仓库规则升为 0.2.0-r18：本版含配置键合并与删除、显示算法行为变化，必须新版本，不覆盖 rc17 的 Release。

## 显示

- **改用原厂显示算法（`display.alg.stock`）改为完全旁路且优先级高于 GPU 后端**：后端下发 `debug.eink.alg.stock`，native `stockOverride()` 让 A2/DU 二值候选与灰阶（含 GPU stock16 重实现）全部让位，像素量化走原厂 CPU 路径；GPU 只保留取帧、全刷复用与触摸加速。该开关不再依赖「GPU 显示后端」。
- **新增每模式「原厂」选项**：快速、极速模式的算法选项加入 `stock`（原厂算法），阅读模式的「原厂误差扩散」改为严格交回 CPU；选中后该模式像素量化不再由 GPU 接管，浅灰底上的规则方格消失。清晰模式保持 GPU stock16，GC16 全刷波形（全刷扫过）与关键帧动画不受影响。
- **A2 局部刷新（切页、滚动）纳入同一判断**：滑动时系统会自动切到均衡模式，实测这条路径落在 `mode` 低字节 `1`，不属五个命名模式，此前仍被 Bayer 接管。现由 `modeStockFor()` 按外部模式号判定，`1/3/4/5` 跟随阅读、`6` 跟随快速、`9` 跟随极速，选中「原厂」后整波交回 CPU。
- **修复波形动画能力下发**：`debug.eink.motion.cap` / `lockcap` 此前无人写入，`HwcBridge.supports()` 恒为假，墨迹晕开、网点长大、扫描线、百叶窗与锁屏过渡请求被静默丢弃。现由后端 `ic_motion_caps` 从 `libeinkgpu` 的 `EINK_MOTION_V2:` / `EINK_LOCK_MOTION_V1:` 标记解析并下发；能力为空时按「未知」照常请求。
- 「需重启」标签只在回执尚未追上配置时显示，已生效的 REBOOT 功能不再常驻该标签；`display.alg.stock` 开启时，波形类与全刷扫过如实标为「依赖未满足」。

## 功能结构调整

- 锁屏「通知来源」与「隐藏锁屏通知」合并为单一「锁屏通知」开关：外层开关控制是否显示，内层仍选「系统通知 / 微信」。
- 下线「体感息屏唤醒」总开关（`wave.master`）：遮挡息屏、移开唤醒各自就是开关，两个都关时服务不监听传感器；「遮挡延时」并入「行为」列表，排列为遮挡息屏、遮挡延时、移开唤醒。
- 删除「Google 设置图标修复」（`fix.google`）：固件拆分包导致覆盖从未生效，目录、文案、后端 overlay 链与构建/校验脚本整体移除。
- 「过渡动画总开关」与「全刷扫过」保留，仅去掉这两项的「实验」标记，其余功能照常显示。
- 旧配置残留键（`fix.google`、`font2.*`、`lock.notifyhide`、`wave.master`）在 App 与后端双侧容忍，升级不卡开机。

## 界面与交互

- 新增「大功能排序」（模块设置内）：八个大功能可上移、下移、恢复默认，属纯界面偏好，不进后端配置。
- 功能页左上角返回按钮由 15sp 放大到 18sp。
- 换页后补一次重绘请求，修复墨水屏上偶发「点击进入大功能后画面不刷新、需要滑动一下才出现」。
- 修复字体页单字搜索「假死」与系统返回落到幽灵分区两个问题（随 rc17 修复一并保留）。

## 版本与文档

- App 版本号 0.1.1-rc17 → **0.2.0-r18**（versionCode 18），后端模块与 `ic_ready` 校验同步。
- 《大功能后端支持清单》补充：自动刷新与体感不依赖后端；字体必须依赖后端；波形动画依赖能力属性下发且与「改用原厂显示算法」互斥。

## 验收范围

本版逐项在本机装机验证：`sys.inkcontrol.ready=1`、无 `error`/`disable_hwc`；锁屏通知单行、体感「行为」三开关、动画页保留总开关与全刷扫过、快速/阅读/极速设为原厂后 `debug.eink.alg.*=stock` 且锁屏唤醒日志仍有 `MOTION_GC`。云端回归、面板、温区、功耗与长稳仍待独立验收。
