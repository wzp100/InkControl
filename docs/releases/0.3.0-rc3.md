# 墨控 InkControl 0.3.0-rc3

面向 **Hisense A5 Pro 经典版黑白屏**的候选预发布（versionCode 30）。**全部增强默认关闭**。安装前请先阅读下方风险提示。

## 更新内容

### 新增

- **「局部刷新」单独选算法**（显示 → 独立场景）：滚动、切页时系统使用的 A2 局部刷新（外部模式 1）以前不属于任何可选场景，固定用 Bayer，所以快速模式选了蓝噪声后，滚动时仍是方格网点。现在可单独选原厂、Bayer、蓝噪声或固定阈值，并有独立迟滞。保持现状时与旧版逐位一致（包括「阅读 = 原厂」时跟随交回原厂）。

### 变更

- **旧「实验室 → 视频抖动算法」下线**，并入「显示 → 视频场景算法」。旧配置里的「原厂误差扩散」选择会自动迁移；新页面已明确选择时以新选择为准。后端在 App 重写配置前继续读取旧键，升级过程中视频算法不变。
- 各场景「原厂」的实际执行路径写进说明与算法 Wiki：清晰由 GPU 逐位复刻（保留全刷扫过），阅读、快速、极速、局部刷新整波交回原厂 CPU，视频为 GPU 复刻。判定规则收拢为 `einkalg::stockFor`，与原生策略探针共用。
- 算法 Wiki 补上快速／极速的「原厂」选项与总开关说明。

## 使用注意

- APK 与后端模块必须同版本、同批安装，升级后完整重启一次；可直接覆盖安装 0.3.0-rc1 / rc2。
- 仅在 `HLTE203T`（Android 10 / arm64）上验证；其他机型与固件不保证可用或可恢复。

## Changes

### Added

- **Separate algorithm for partial refresh** (Display → Separate scenarios): the A2 partial refresh the system uses while scrolling and switching pages (external mode 1) previously belonged to no selectable scope and always used Bayer, so scrolling still showed a grid after choosing blue noise for Fast mode. It can now use stock, Bayer, blue noise or direct threshold, with its own hysteresis. Keeping the default is bit-identical to the old behavior (including following Reading back to stock when Reading is set to stock).

### Changed

- **The legacy Lab option "Video dithering algorithm" is retired** and merged into Display → Video scenario algorithm. An old "stock error diffusion" choice migrates automatically; an explicit choice on the new page wins. The backend keeps reading the old key until the app rewrites the configuration, so the video algorithm does not change during the upgrade.
- The guide and algorithm Wiki now state how `stock` runs per scope: Clear uses a bit-exact GPU replica (keeping the full-refresh sweep), Reading, Fast, Extreme and partial refresh hand the whole wave to the stock CPU path, and video uses a GPU replica. The rule lives in `einkalg::stockFor`, shared with the native policy probe.
- The algorithm Wiki now lists the stock option for Fast/Extreme and documents the master switch.

## Notes

- Install the APK and backend module from the same version together and restart fully after upgrading; installing over 0.3.0-rc1 / rc2 is supported.
- Verified only on `HLTE203T` (Android 10 / arm64); other devices and firmware are not guaranteed to work or be recoverable.
