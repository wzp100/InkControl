# 墨控 InkControl 0.1.0-rc16

面向 **Hisense A5 Pro 经典版黑白屏**的候选预发布。本版本在 rc15 基础上新增「自动刷新」：统计点击、滚动、按键与阅读界面操作，达到设定次数后由系统端执行墨水屏清晰刷新，并支持周期性刷新；分类提供总开关、触发方式、触发次数、合并间隔、刷新前延时、阅读界面识别、周期与应用黑白名单八组选项，全部分类默认关闭。保留分模式算法、视频独立选择、独立迟滞及现有默认配置；**62 个增强全部默认关闭**。锁屏新增通知来源选择，默认统计系统可清除通知，也可切换为微信未读；自定义锁屏样式依次为编辑排版、瑞士网格、像素、液态玻璃，自定义锁屏不再叠加原厂底栏，像素主题底部改为上滑箭头；功能首页集中显示就绪状态和语言切换。

自动刷新通过随 App 提供的无障碍服务统计操作，只按刷新总开关维护该服务；真正的刷新由墨控在 system_server 的钩子调用原厂刷新入口完成。应用黑白名单按当前前台应用过滤点击、滑动、按键与阅读界面的计数：开启后默认白名单，白名单与黑名单各自保存一份名单，在条目内切换模式后用同一个按钮勾选应用，关闭时对所有应用生效；周期性刷新不受名单限制。刷新入口名与实机行为仍需实机验收；自动刷新为实验功能，默认不开启。

使用本 Release 的 APK；配套后端已内置，也提供同版本 ZIP。适配门槛：HLTE203T、API29、arm64、L1732.6.01.02 及准确原厂输入哈希。rc13 起的新签名不能覆盖旧签名 App；首次迁移先备份配置并卸载旧 App，再安装新版与匹配后端。
