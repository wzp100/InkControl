# 墨控 InkControl 0.3.0-rc1

面向 **Hisense A5 Pro 经典版黑白屏**的候选预发布（versionCode 28）。本版本并入社区贡献者 [liuqianhe](https://github.com/liuqianhe) 在 PR #1 中提交的大批功能，并由维护者做了安全与发布流程整理。**全部增强默认关闭**；安装前请先阅读下方风险提示。

## 更新内容

### 新增（贡献者：liuqianhe）

- **自动刷新**：按触摸、按键、阅读界面或周期触发全刷，次数与合并间隔可自定义，支持应用黑白名单。
- **体感**：遮挡距离传感器息屏、移开唤醒。
- **翻页动画**：六种分块揭示风格，由 GPU 显示后端的波形层实现，按「目标阅读器」名单触发。
- **锁屏**：新增编辑排版-横、横-逆与液态玻璃样式；设备状态条、倒数日（含农历）、天气 App 数据源、通知来源可选。
- **字体**：直接替换系统字体并可一键恢复原厂字体。
- **系统增强**：系统应用卸载/还原、系统设置快照与写回、冻结安全输入服务后仍可输入密码、导航键白底黑键、控制中心列出第三方磁贴、E-Ink 面板最多五个自定义按钮。
- **显示**：原厂算法可按场景单独选择；全刷扫过新增六种形状并可独立设置方向与速度。
- **界面**：功能列表紧凑布局、拖动排序、桌面长按快捷方式、结果提示时长可选、「关于」页手动检测更新。

### 变更

- **翻页动画需要同时开启 GPU 显示后端**。贡献者版本中依赖无源码第三方显示库与常驻程序的「独立库模式」未并入：本项目只分发由本仓库源码构建的二进制与原有的厂商派生 HWC。对应的「点击与横向滑动翻页」「实体音量键翻页」「连续操作保护」三个选项随之移除，旧配置中的残留键会被忽略。
- 「Google 设置图标修复」下线（在本固件的拆分资源上从未生效）。
- 运行监测改为连续 3 次 GPU 回退才停用显示后端；系统 3 分钟内未完成启动时自动停用后端并重启。
- App 新增联网权限，仅用于「关于」页手动检测更新；新增存储读取权限用于选择字体文件。自动刷新与体感各自使用一个无障碍服务，仅在对应开关开启时启用。

### 修复

- 配置校验恢复为严格匹配候选值，自由文本只对字体路径等明确声明的项放行。
- 「检测更新」与仓库链接指向本仓库。
- 补齐全部新增界面文案的英文翻译。

## 使用注意

- APK 与后端模块必须同版本、同批安装，升级后完整重启一次。
- 仅在 `HLTE203T`（Android 10 / arm64）上验证；其他机型与固件不保证可用或可恢复。
- 版本号沿用本仓库的 `X.Y.Z-rcN` 规则；贡献者分支上的 `0.2.x-rNN` 版本使用不同签名，不能与本版本互相覆盖安装。

Candidate prerelease (versionCode 28) for the **Hisense A5 Pro 经典版 (Classic Edition), monochrome**. This version merges a large set of features contributed by [liuqianhe](https://github.com/liuqianhe) in PR #1, with security and release-pipeline cleanup by the maintainer. **All enhancements default off.** Read the risk notice below before installing.

## Changes

### Added (contributed by liuqianhe)

- **Auto refresh**: full refresh triggered by taps, keys, reading screens or a period, with custom counts and debounce and an app allow/deny list.
- **Proximity**: sleep when the proximity sensor is covered, wake when uncovered.
- **Page-turn animation**: six banded reveal styles rendered by the GPU display backend's waveform layer, triggered by the target-reader list.
- **Lock screen**: Editorial landscape, landscape reversed and Liquid glass styles; device-status strip, countdowns (including lunar dates), weather-app data source, selectable notification source.
- **Fonts**: replace the system font directly, with one-step restore of the stock font.
- **System**: remove/restore system apps, snapshot and write back system settings, password entry after freezing the secure input service, black-on-white navigation keys, third-party tiles in the control center, up to five custom buttons on the E-Ink panel.
- **Display**: stock algorithm selectable per scene; six full-refresh sweep shapes with independent direction and speed.
- **UI**: compact feature list, drag ordering, launcher long-press shortcuts, selectable notice duration, manual update check on the About page.

### Changed

- **Page-turn animation requires the GPU display backend.** The contributor's standalone mode, which depended on a closed-source third-party display library and resident program, was not merged: this project ships only binaries built from this repository's source plus the existing vendor-derived HWC. The three options tied to it (tap/swipe page turns, volume-key page turns, rapid-turn protection) were removed; leftover keys in old configurations are ignored.
- The Google settings icon fix was retired (it never took effect on this firmware's split resources).
- Runtime monitoring now disables the display backend after three GPU fallbacks instead of one; if the system does not finish booting within three minutes the backend is disabled and the device restarts.
- The app gains network permission, used only for the manual update check on the About page, and storage read permission for choosing font files. Auto refresh and Proximity each use an accessibility service that is enabled only while its switch is on.

### Fixed

- Configuration validation again requires listed values; free text is accepted only for explicitly declared items such as font paths.
- The update check and repository links point to this repository.
- English translations were added for all new UI text.

## Notes

- Install the APK and backend module from the same version together and restart fully after upgrading.
- Verified only on `HLTE203T` (Android 10 / arm64); other devices and firmware are not guaranteed to work or be recoverable.
- Versions follow this repository's `X.Y.Z-rcN` scheme. The contributor fork's `0.2.x-rNN` builds use a different signature and cannot be installed over this version or vice versa.
