# 墨控 InkControl 0.2.7-r27（versionCode 27）

## 更新内容

### 新增

- **快捷面板多一格按钮**：按钮位置从 4 个扩到 5 个，出厂顺序改成 WiFi、蓝牙、自动刷新、翻页动画、截屏便签；五格并排时每格变窄，按钮文字会自动缩一档。

### 变更

- **总开关没开也能先改配置**：调整配置文件在没有开启总开关修改的逻辑。
- 快捷面板页顺序调整：「点完收起面板」「截屏便签尺寸对齐」挪到按钮顺序下方；「恢复默认顺序」右侧直接跟出厂名单。
- **翻页动画页删掉两条过期说明**：底部「与「GPU 显示后端」只能二选一」（r26 起已能共存）和「选完下次翻页生效，无需重启」。

## 使用注意

- 本次只改界面与配置保存时机，**后端能力没有变化**：安装包与后端模块版本号必须一致，升级时同批重装并完整重启一次。
- 总开关关闭时保存的只是取值，**开关本身仍需手动打开**才会生效。
