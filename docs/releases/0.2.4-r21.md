# 墨控 InkControl 0.2.4-r21

面向 **Hisense A5 Pro 经典版黑白屏**的候选预发布。本版把「大功能」页统一成紧凑布局：编号小节 + 下拉／单行开关，说明文字全部收进详情页；下拉的选中态改成上下双线包裹；首页与分类卡上的「已开启 / 总数」全部去掉，只留「待重启」「异常」。同时修掉「字体」「快捷面板修改」这类直落功能页点左下角「功能」不返回的问题。**全部增强默认关闭**（「设备状态」的四项显示开关与「截屏便签对齐尺寸」默认开启）。

版本号按仓库规则升为 0.2.4-r21，`versionCode` 取 **22**——上一版 0.2.3-r20 的 `versionCode` 已经是 21（历史遗留，比版号多一格），本版必须比它大才能正常覆盖安装。

## 全局紧凑页

- 所有大功能分类页统一走 `compactCategoryPage()`：分区标题带两位编号（`01`、`02`…）、多值项排成「标签 + 当前值 ▾」的下拉行、布尔项排成单行开关，名单／预览／自定义输入／算法页这类还在独立页面的项只留一个「名称 ›」入口。
- 分类页不再铺 `summary` / `what`，需要看说明就点进去看详情页；一屏能看完的分类不再需要长滚动。
- 「翻页动画」「系统应用卸载/还原」仍保留各自的独立界面（前者是参数页，后者是系统应用清单），不套通用紧凑页。

## 下拉选中态

- 点开下拉后不再用勾选图标或灰色底：**当前值那一项上下各一条 2dp 实线**（两道下划线把选中行夹在中间），行内文字加粗，其余行保持原样。
- 只影响观感，取值与保存逻辑不变。

## 去掉数量口径

- 首页标题下方的「N 已开启 / 总数」不再统计、不再显示，只剩「待重启」与「异常」（都为 0 时整行不出现）。
- 分类卡右侧的「(n/m) 已开启」整段删掉，卡片只剩分类名、一行简介与异常提示，卡片高度随之变矮。
- README 的「82 个增强」也改成「全部增强」，以后新增功能不必再回来改数字。

## 默认顺序调整

- `Guide.CATEGORIES` 把「系统应用卸载/还原」移到最后：它是首页里唯一会动系统应用的入口，不该夹在常用分类中间。
- 默认顺序为：显示 → 锁屏主题 → 动画 → 自动刷新 → 字体 → 体感 → 桌面 → 系统增强 → 快捷面板修改 → 系统应用卸载/还原 → 实验室。
- 设备上如果已经有自定义排序（`ui-category-order.xml`），要看到新默认顺序需要先备份并删除该文件。

## 直落功能页的返回修复

- 「快捷面板修改」「字体」是直接落到功能详情页的：`category` 为空、只有 `featureId`。`MainActivity.switchTab` 原来只判 `!category.isEmpty()`，所以在这两页点左下角「功能」什么都不发生，只能用系统返回或左上角「‹ 功能」。
- 判据改成两者任一非空即回首页，滚动位置保留。

## 面板「锁屏主题」改为跳转

- 刷新面板上的「锁屏主题」原来点一下就地开关整组锁屏，误触就把整套锁屏关掉；现在单击与长按一致：收起面板直接进「锁屏主题」（锁屏自定义）那一页挑样式。
- 「自动刷新」「遮挡息屏」两项保持点一下就地开关不变。

## 「显示信息修改」就地多选

- 锁屏主题紧凑页里原来要点进独立页面的「显示信息修改」，改成一行展开式多选：点标题就地展开四项，每项前面一个方框，**勾一项存一项**；收起时右侧显示「3 / 4 ▾」。
- 逐项说明与「图标版 / 文字版」切换仍在原页面，展开区底部留了「显示方式与说明 ›」入口。

## 字体介绍文案

- 「字体」大功能下的介绍删掉「点『应用』立刻全局生效，不用重启」，只留「把系统字体换成目录里的任意 TTF/OTF。」——热切换的说明在功能页与详情页里已经写过，分类页不必重复。

## 工具

- `tools/test.py` 新增 `--fast`：只跑 Java 侧与目录导出，约 4.5 秒；全量约 292 秒，慢在 `test_gpu_diagnostics` 的 bash 替身进程与超时，与构建脚本无关。

## 验证

- 电脑端：`tools/test.py --fast` 全绿（CoreTest 1427、PolicyTrackerTest、HookIntegrationTest、TextCatalogTest，`guide checks 849`）；`check_docs.py` / `check_repository.py` 通过。
- 真机（`HLTE203T`）：安装本版并完整重启后 `sys.inkcontrol.ready=1`、模块目录无 `error`，首页显示 `v0.2.4-r21`、状态「就绪」，无「存在未知配置字段」；「字体」页点左下角「功能」回到首页且保留滚动位置。
- 本版没有翻页动画：那一组功能与它依赖的显示库另起一版，本版后端不含 `pageanim.*` 键。

**未验收**：紧凑页在长名单分类（系统增强 6 个小节、快捷面板修改 4 行）上的滚动观感、下拉在 1-bit 屏上的刷新残影、以及长时间使用后的功耗与温区。未列出的项不做承诺。
