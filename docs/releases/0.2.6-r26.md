# 墨控 InkControl 0.2.6-r26

面向 **Hisense A5 Pro 经典版**（`HLTE203T` / Android 10 / arm64）的候选版本，版本号 `0.2.6-r26`，versionCode 26。全部增强默认关闭。

## 本版内容

- **翻页动画与 GPU 显示后端可同时启用**：把翻页动画的分块揭示重写成 GPU 波形条带相位（`native/service_fusion.hpp`），`display.gpu` 与 `pageanim.master` 同开不重启即生效；触发范围由「目标阅读器」名单收窄。分带按 `bandTail` 延长总帧数，修掉「刷新不干净」的浅灰残影。
- **过渡动画的场景可选「无」**：打开应用、返回桌面、应用内前进/后退、对话框与菜单、进入锁屏、唤醒过渡的第一项都是「无」，等于保持原厂瞬间切换（旧版这里是开关）。
- **全刷扫过独立成组**：从「各场景用什么动画」拆出来单列，下有风格、方向、速度三项。风格按翻页动画那套写法补了横向展开、纵向展开、斜向分块、反斜向分块、环绕分块、中心展开；速度 1/4/8/12/18 帧，最快档几乎整屏同时刷新，去残影效果不变。「擦除方向」改名「动画擦除方向」以免和全刷方向混淆。
- **修复锁屏与唤醒的动画不生效**：熄屏送图门控用了会随原厂输入模式变化的位掩码，锁屏请求从未被消费、被全刷扫过顶替；唤醒走的又不是同一种波形布局，还会被冷屏保护跳过。现已分别按位图路径与显式唤醒请求放行，锁屏百叶窗、唤醒扫描线均已上机验证。
- **关于页**：首页右上角与「模块设置」都能进入，列出版本、作者、上游仓库与参考项目；「检测更新」只在点击时比对 GitHub 最新 Release，不做自动更新、下载或安装。为手动检测新增 `INTERNET` 权限。检测结果按版本号逐段比较，线上还停在旧版本时会提示「本机比线上发布更新」，不会把旧发布报成新版本。
- **文档**：新增 `docs/字体替换机制.md`、`docs/E-Ink快捷面板.md`、`docs/翻页动画4块原型预研.md`，只留可直接参照的机制、路径、命令与 hook 点；`docs/大功能后端支持清单.md` 补充「按应用动态切换 HWC 为什么不可行」与可行路线的代价。
- **署名**：翻页动画由 **nuku 大佬**制作，经其同意整合进墨控；第三方二进制与 HWC 派生库的权利归原权利人所有，见 `NOTICE.md`。

## 重要限制

- 融合模式只按「目标阅读器」名单触发，**没有手势识别**：同一应用内的滚动、弹窗、页内重绘同样会播放分带（波形层分不出翻页和滚动）。「点击与横向滑动翻页」「实体音量键翻页」「连续操作保护」三项只在 GPU 后端关闭（独立库模式）时生效。
- 分带揭示与「动画」里的波形效果共用同一条波形时序：全刷扫过等效果接管当前帧时，融合分带让位。
- App 里两个开关显示「已开启」只代表配置；改 `display.gpu` 需要完整重启，`pageanim.master` 才是热更新。分析见后端支持清单 5.1–5.3。
