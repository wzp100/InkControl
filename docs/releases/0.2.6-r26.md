# 墨控 InkControl 0.2.6-r26

面向 **Hisense A5 Pro 经典版**（`HLTE203T` / Android 10 / arm64）的候选版本，版本号 `0.2.6-r26`，versionCode 26。全部增强默认关闭。

## 本版内容

- **关于页**：首页右上角与「模块设置」都能进入，列出版本、作者与贡献者、上游仓库、参考项目与社区署名；「检测更新」只在点击时比对 GitHub 最新 Release，不做自动更新、下载或安装。为手动检测新增 `INTERNET` 权限。
- **文档**：新增 `docs/字体替换机制.md`、`docs/E-Ink快捷面板.md`，只留可直接参照的机制、路径、命令与 hook 点；`docs/大功能后端支持清单.md` 补充「按应用动态切换 HWC 为什么不可行」与可行路线的代价。
- **署名**：翻页动画由 **nuku 大佬**制作，经其同意整合进墨控；第三方二进制与 HWC 派生库的权利归原权利人所有，见 `NOTICE.md`。

## 重要限制

- **翻页动画与 GPU 显示后端（`display.gpu`）仍不能同时启用**，同一份 `hwcomposer.ums512.so` 开机只挂一份，切换必须完整重启；App 里 `display.gpu` 显示「已开启」只代表配置。按白名单动态换库、二进制融合等路线的分析见后端支持清单 5.1。
- 本版只新增界面与文档，未改动显示后端逻辑；关于页观感与「检测更新」的网络可达性由使用者在真机上确认。未列出的效果不做承诺。

## 验证范围

电脑端：全量构建（javac 全量 / dex / v3 签名）、`tools/test.py --fast`、`check_docs.py` / `check_repository.py` / `check_i18n.py` 通过。真机采用 `install -r` 升级 APK 并同批重装同版本后端模块后完整重启；界面由使用者自行查看。以上不等于面板观感、功耗、温区或长期稳定验收。
