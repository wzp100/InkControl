# 墨控 InkControl 0.2.6-r26（versionCode 26）

## 更新内容

### 新增

- **翻页动画与 GPU 显示后端可以同时启用**：把分块揭示重写成 GPU 波形分带，`display.gpu` 与 `pageanim.master` 同开不用重启；触发范围由「目标阅读器」名单收窄。
- **部分场景动画可设置「无动画」**
- **「全刷扫过」独立成组**：添加`扫过风格`，添加`扫过速度` 支持更多动画。
- **面板新增「全刷扫过」与「刷新格言」**
- **锁屏格言可以手动刷新**
- **格言能用广播调用**：详见 `docs/刷新格言外部调用.md`。
- **音量键翻页按习惯定方向**：让音量+＝上一页、音量-＝下一页，不再沿用上一次点击的方向。
- **添加关于界面**

### 变更

- **「锁屏主题」改名为「锁屏显示」**。
- **排序方式修改**：「功能列表排序」与「快捷面板的按钮顺序」采用更优雅的方式进行调整。
- **翻页动画方向跟手势走**：左滑／点右半屏＝下一页，右滑／点左半屏＝上一页，竖向滚动不受影响。
- **总开关适配紧凑布局**：「翻页动画总开关」与「快捷面板修改总开关」适配紧凑布局。

### 修复

- **锁屏与唤醒的动画不生效**：送图门控的位掩码判断会随原厂输入模式变化，且唤醒走了另一种波形布局，现按位图路径与显式唤醒请求分别放行。
- **融合刷新不干净**：分带按 `bandTail` 延长总帧数，修掉浅灰残影。
- **检测更新把旧版报成新版**：改为逐段比较版本号，线上落后时提示「本机比线上发布更新」。
- **「模块设置 → 名词解释」点不进去**：子页判断排在标签页分支之后，已调整顺序。
- **面板动作报「不支持的面板开关」**：开关白名单漏登记新动作，已同步。

## 使用注意

- 融合模式只按「目标阅读器」名单触发，**没有手势识别**：同一应用内滚动、弹窗、页内重绘同样会播放分带。「点击与横向滑动翻页」「连续操作保护」只在 GPU 后端关闭时生效。
- 改 `display.gpu` 需要完整重启，`pageanim.master` 是热更新；App 显示「已开启」只代表配置。
- 安装包与后端模块版本号必须一致，升级时同批重装并完整重启一次。
