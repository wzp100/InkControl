# 墨控 InkControl 0.2.3-r19

面向 **Hisense A5 Pro 经典版黑白屏**的候选预发布。本版把 E-Ink 刷新面板（从屏幕左下角或右下角上滑唤出的那块）底部改成**四个可自定义的位置**、新增「截屏便签」那一格的三种去处，并把「自定义锁屏」页的「使用此主题」放到效果图标题行右侧、分类与页面统一改名为「锁屏主题」。**82 个增强全部默认关闭**（「设备状态」的四项显示开关除外，它们默认开启）。

版本号按仓库规则升为 0.2.3-r19：本版新增配置键 `qs.panel.btn1`–`btn4`，并给取值校验加了单包名类型（`@package`），旧后端不认这些键，必须新版本。

## 刷新面板底部：四个位置自己定

- 「快捷面板修改」下不再分「按钮」与「点完的收尾」两节，全部收进「按钮」：**快捷面板按钮**（总开关，页内含顺序与「截屏便签」位置）、**「截屏便签」这个位置**、**点完收起面板**。
- 总开关页里直接给出**按钮顺序**：四行「序号 · 动作」，点「更换」换动作、「←」「→」左右挪，末尾可恢复默认（WiFi · 蓝牙 · 墨控快捷设置 · 截屏便签）。顺序不另存一份，挪位置就是**把两格的动作对调**，所以配置里只有四个位置的动作，没有第五个「顺序」键。
- 每个位置的可选动作就是控制中心那排磁贴：**WiFi、蓝牙、铃声、飞行模式、手电筒、自动旋转、整屏翻页、免打扰、省电模式、悬浮球**，再加**墨控快捷设置**与**截屏便签位置**。动作都走系统界面本进程的同一套调用（与原厂磁贴同一份权限）：WiFi/蓝牙用各自 Manager，铃声走 `setRingerModeInternal`（响铃 → 振动 → 静音），飞行模式用 `ConnectivityManager.setAirplaneMode`，铃声与整屏翻页读写各自的原厂设置键，悬浮球照原厂磁贴发 `com.fooview.android.intent.SET_ICON_STATUS`。
- 图标沿用系统界面自己的那套矢量图并固定 28dp、染成黑色；「墨控快捷设置」用墨控齿轮，「截屏便签」位置换成应用时用那个应用自己的图标。
- 布局仍然**只有一行**：四个位置都标 `two`，`InkButtonsParent` 按每行个数平分宽度，面板高度与原厂一致（`mLineOneHeight` 仍为 180）。
- 点完的收尾：`qs.panel.close` 打开时，点完动作（含隐藏的「截屏便签」格）就调原厂 `closePopWindow()` 收起面板；「墨控快捷设置」与「截屏便签」这两类本来就要跳到别的界面，一律先收起。

## 「截屏便签」那一格：留着、换墨控、隐藏，或换成别的应用

- `qs.pinlaunch` 从「开关」变成三选一加一：**原厂截屏便签**（关）/ **打开墨控**（`default`）/ **隐藏这个格子**（`hide`）/ **其他应用**（存包名）。选「隐藏」时这一格不出现，后面的按钮自动往前挪；选应用后点它直接打开，找不到应用时提示而不报错。
- 「其他应用」用系统已安装的启动器应用列表来选，存的是包名（新增取值类型 `@package`：只允许合法包名，空串表示未指定）。App 侧与后端校验都认这个类型。

## 锁屏主题

- 分类「锁屏」与页面「自定义锁屏」统一改名为**锁屏主题**；`FeatureCatalog` 的分组名、`Guide` 的分类表、首页「点进每一项可以看到动画演示或效果图」的判定、快捷设置页与恢复默认的文案都跟着改，跳转仍按功能 id（`lock.style`）走，不受改名影响。
- 效果图标题行左侧仍是「效果图 · 样式名」，**右侧新增「使用此主题」**：选完别的样式不用再滚到列表底部，标题行就能直接应用。原来效果图下方那颗整宽「使用「…」」按钮取消，避免同一页出现两个同样的按钮。
- 「快捷面板修改」与这几项的说明文字按「说清一件事」重写，去掉了大段背景介绍。

## 验证范围

构建与电脑端测试（`CoreTest` / `GuideTest` / `TextCatalogTest` 及 Python 单测）通过；实机部分见下文「已确认 / 未确认」，未列出的项不做承诺：面板观感、功耗、温区与长期稳定仍待独立验收。

### 已确认（A5 Pro 经典版，HLTE203T / Android 10）

- 面板底部四格横排：WiFi / 蓝牙 / 墨控快捷设置 / 第四格，图标与文字完整，面板高度与原厂一致。
- 顺序：`←`、`→` 交换后配置里两格动作确实对调，面板下一次唤出即为新顺序；「恢复默认顺序」四格全部回到 WiFi · 蓝牙 · 墨控快捷设置 · 截屏便签。
- 更换动作：第 3 格换成「自动旋转」、第 1 格换成「手电筒」，面板图标与文字同步。
- 「截屏便签」这一格四选一都试过：原厂（图标文字与原厂监听器原样保留）、打开墨控、隐藏（只剩三格且宽度均分）、其他应用（选 Aurora Store 后显示它自己的图标，点开直达该应用）。
- 动作本身：WiFi 关→开并弹出顶部 toast「WiFi 已打开」，面板随后收起；手电筒开/关在 `dumpsys media.camera` 里分别出现 `Torch ... turned on/off`；整屏翻页写入 `Settings.Global` 的 `slide_turn_over_page`，取值语义与原厂 `TurnOverPageTile` 一致（0 关 1 开）。
- 锁屏主题：选别的样式后标题行右侧出现「使用此主题」，点按后 `lock.style` 立刻改值、效果图重绘、按钮消失。

### 未确认

- 铃声、飞行模式、免打扰、省电模式、悬浮球五项只做了代码层核对，没在设备上逐一点测。
- 关掉「快捷面板按钮」总开关后，原厂面板是否完全恢复原样。
- 长时间反复唤出/收起与后台功耗。
