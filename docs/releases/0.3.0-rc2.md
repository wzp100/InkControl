# 墨控 InkControl 0.3.0-rc2

面向 **Hisense A5 Pro 经典版黑白屏**的候选预发布（versionCode 29）。本版本是 0.3.0-rc1 之后的修复、加固与代码整理，没有新增功能；**全部增强默认关闭**。安装前请先阅读下方风险提示。

## 更新内容

### 变更

- **面板兜底页只允许系统界面调用**：`PanelToggleActivity` 加上平台签名权限，其他已安装应用不能再借它切换自动刷新、锁屏主题等五个开关。
- **已下线的配置键统一来源**：App 解析与后端校验共用功能目录导出的同一张表（`lib/retired.txt`）。
- 移除显示服务里遗留的翻页动画早期原型代码（默认不生效，但每帧多读一次属性）。
- 设备脚本不再内置本机路径和局域网地址，改用环境变量 `ADB`、`INK_WIRELESS`。
- 应用图标恢复为 0.1.x 的原图标。
- 系统界面与桌面里弹出的提示（面板开关、换格言等）跟随墨控的界面语言显示英文。
- 哪些配置键必须存在、哪些默认开启，改由功能目录统一导出，后端校验、包校验与测试共用；设置页的各组页面从主界面类拆到独立的类里（无行为变化）。

### 修复

- **从 0.1.0-rc15 升级时后端安装被判「配置无效」而中止**：0.3.0-rc1 的校验把锁屏通知、倒数日、体感等新增功能当成了必须存在的键。
- 「检测更新」在只有候选版本时始终失败（原接口不包含预发布版，且匿名调用容易被限流；现改读发布页订阅源），以及把正式版判成比同号候选版旧的问题。
- App 读取含 `pageanim.touch` / `pageanim.keys` / `pageanim.debounce` 的旧配置时报「存在未知配置字段」。

## 使用注意

- APK 与后端模块必须同版本、同批安装，升级后完整重启一次；可直接覆盖安装 0.3.0-rc1。
- 仅在 `HLTE203T`（Android 10 / arm64）上验证；其他机型与固件不保证可用或可恢复。

Candidate prerelease (versionCode 29) for the **Hisense A5 Pro 经典版 (Classic Edition), monochrome**. This version is a code cleanup and hardening pass after 0.3.0-rc1 with fixes and no new features. **All enhancements default off.** Read the risk notice below before installing.

## Changes

### Changed

- **The panel fallback page accepts System UI only**: `PanelToggleActivity` now requires a platform-signature permission, so other installed apps can no longer use it to flip the five whitelisted switches such as auto refresh or the lock-screen theme.
- **One source for retired configuration keys**: app parsing and backend validation share the table exported from the feature catalog (`lib/retired.txt`).
- Removed an early page-turn prototype left in the display service (inactive by default, but it read a property on every frame).
- Device scripts no longer embed machine-specific paths or LAN addresses; use the `ADB` and `INK_WIRELESS` environment variables.
- The launcher icon is restored to the 0.1.x artwork.
- Toasts shown from System UI and the launcher (panel switches, motto changes and so on) follow InkControl's UI language.
- Which keys are mandatory and which default on is now exported from the feature catalog and shared by backend validation, package verification and tests; settings pages were split out of the main activity class into separate classes with no behavior change.

### Fixed

- **Backend installation aborted with "invalid configuration" when upgrading from 0.1.0-rc15**: validation in 0.3.0-rc1 treated newer features such as lock-screen notifications, countdowns and Proximity as mandatory keys.
- The update check always failed while only candidate versions existed (the previous endpoint excludes prereleases and anonymous calls are easily rate-limited; it now reads the releases feed), and it ranked a stable version below its release candidates.
- The app rejected old configurations containing `pageanim.touch`, `pageanim.keys` or `pageanim.debounce` as unknown fields.

## Notes

- Install the APK and backend module from the same version together and restart fully after upgrading; this version installs over 0.3.0-rc1.
- Verified only on `HLTE203T` (Android 10 / arm64); other devices and firmware are not guaranteed to work or be recoverable.
